## 🧬 Featured Projects

### 1. *E. coli* Whole Genome Sequencing — Variant Analysis

An end-to-end bacterial WGS analysis project using Illumina paired-end sequencing data to identify and annotate candidate genetic variants.

**Workflow:**

```text
Raw FASTQ Reads
      ↓
Quality Control — FastQC
      ↓
Read Trimming — fastp
      ↓
Reference Indexing & Alignment — BWA
      ↓
BAM Processing & Quality Assessment — SAMtools
      ↓
Variant Calling & Filtering — BCFtools
      ↓
Variant Annotation — SnpEff
      ↓
Candidate Variant Review
```

**Technologies:** Linux, Bash, FastQC, fastp, BWA, SAMtools, BCFtools, SnpEff

🔗 [View Project on GitHub](https://github.com/mayankpatidar77/E-coli-NGS-Variant-Analysis)
